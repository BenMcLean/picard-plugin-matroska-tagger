# picard-plugin-matroska-tagger
This plugin adds matroska tagging to [Picard 3](https://picard.musicbrainz.org/) via [MKVToolNix](https://mkvtoolnix.download/).

Created by Ben McLean in 2026.

Upgraded from the [Picard 2 version](https://gist.github.com/BenMcLean/107663c60c2e61c864c57cb330c605ae).
